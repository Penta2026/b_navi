# 2026-11-22 JR駅の名称検索復旧

## 背景
「尾道駅」が施設名検索に出ない。従来は公開Nominatim/Photonの結果だけを照合しており、駅の地理院住所検索やオフライン名寄せはなかった。正確な不一致理由は外部サーバーの再現取得ができないため未断定。

## 今回の修正
- 旧PWA `Penta2026/michinotochu` の `data/jr_stations.json`（4,321件）をB_Naviに同名でコピー。旧Git SHA `a22f0d8c1cfe8f40d565371c54a0091bc604e540`。駅名・緯度・経度が格納された既存データ。
- 駅名クエリ `尾道駅`・`JR尾道駅`・`ＪＲ 尾道駅`・`JRの尾道駅` はローカル駅データへ先に照合。完全一致を使い、「東尾道」「新尾道」を混同しない。
- `尾道` のように「駅」が付かない入力は、既存のオンライン検索結果がないときにローカル駅候補を使用。通常の施設検索・住所検索は維持。
- 駅結果は既存の「出発地・目的地・経由地・お気に入り」選択に接続。GPS・ルート・GPX処理は変更しない。
- `station-search.js` と `data/jr_stations.json` をService Workerアプリシェルに追加し、PWA更新時に端末へ保存。検索用駅データはユーザー端末内で参照できる。
- 旧PWAデータの座標は駅の代表点であり、入口・車道上の点・乗車位置とは限らない。地図を見て確認する案内を表示。

## 検証
- ローカルNodeテスト95件中94件合格・1件は簡易データのみのため意図的にスキップ。GitHub CIでは本番4,321件のファイルで全件検証。
- ブラウザ模擬テスト：外部施設検索をHTTP503にしても「尾道駅」が表示され、目的地座標に `34.404838,133.193008` を設定できた。続けて「ＪＲ 新尾道駅」が出て、別駅の混入なし。駅データは1度だけ読み込む。
- 住所検索・モバイルタブ・ナビの既存スモークを通過。
- Android実機・公開Nominatim/Photonの状況・駅データの更新時期および現地入口位置は未検証。

## 注意
駅データ自体は旧PWAから複製したもの。駅の現存・営業・最新位置の確約ではない。旧ソースに別の利用条件があれば従う。駅データの一括ダウンロードに外部地図タイルは使用しない。
