# フリー走行の案内ルート線を非表示にする（2026-11-22）

- フリー走行中は `refreshMap()` の描画入力を空配列とし、案内ルート線だけを即座に非表示にする。
- スタート S・ゴール G・経由地は `getMarkers()` で従来どおり表示する。
- 描画とルート保存を分離し、`state.routes`、`state.gpsPoints`、`state.currentGpx`、マイルート集、ルート検索結果を削除しない。
- GPS更新中にも案内線は出ない。フリー走行終了後は元の案内線表示を復元する。
- 旧来のフリー走行終了後GPX保存・共有 UI、レーダー切替、ナビGPS追従を維持。
- 変更箇所：`app.js`、`ride-radar.js`、`sw.js`、ブラウザテスト、Nodeテスト。
- 確認：シミュレーションおよび静的テスト。実走機での表示は未検証。
