# B_Navi POI検索復旧 (2026-11-22)

問題: Photon/Nominatimが候補を返しても、名称一致度 `>=55` の厳格フィルタで施設を過剰除外していた。カテゴリ名「カフェ」「ガソリンスタンド」等で探すと、実際の店舗名に検索語が含まれず0件になる。

変更:
- Photon/Nominatim候補にOSM施設分類を保持し、カテゴリ検索は実際のタグ一致を許容する。名前の完全・部分一致は引き続き優先。地域を指定した検索の他市候補は除外。
- Photonをまず検索、見つかる施設が少ない場合のみ従来のNominatimへフォールバック。日本語の地域指定を含む文字列がうまく解釈されなければPhotonを施設名だけで再検索（地域チェック維持）。
- 厳密一致ゼロでも、同じ地域・POI分類・名前の2文字以上の共通部分がある結果は「関連候補（名称を確認）」として表示。場所が違う、名前が無関係、単なる地名の結果は表示しない。
- 全サービス障害と0件を区別。リトライが早すぎる場合は既存結果を消去しない。
- 検索結果の地理座標は地図で確認する。Photon/Nominatim公開データだけではすべての施設を網羅できない。
- 同一GitHub Pages配信のJR駅検索、地理院住所検索、ルート計算、実走GPX保存は変更なし。

テスト:
- Nodeテスト 96/96 (ローカル版・駅検索追加前のバックアップベース)。
- 模擬ブラウザ: 区域＋カテゴリで異なる店名を検索し正しい市だけ表示、目的地登録。従来スモーク・住所検索・モバイルタブ・経路設定・GPXフリー走行などを追加実行。
- GitHub公開後のテスト結果はGitHub Actionsで別途確認する。
- 実際の外部Photon/Nominatim APIがその時点でどの候補を返すかは未検証。実地検索確認が必要。
