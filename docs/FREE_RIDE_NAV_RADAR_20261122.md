# B_Navi 走行モード整理（2026-11-22）

## 実装した操作の流れ

1. ルート検索を行わずに走る場合は、画面下部「🏍 走行」から **フリー走行開始**。このメニューには単独の「レーダー開始」ボタンを置かない。
2. フリー走行中はGPS実測軌跡を端末側へ記録。終了すると通常画面へ戻り、ルートパネル最下部の「📍 実走GPX」を自動で開く。記録点があると「保存」「共有」「破棄」が表示される。GPXは自動的にダウンロードしない（ユーザーが保存を押す）。記録ゼロの場合は保存可能と誤表示しない。
3. ルート計算／GPX取込みで案内できるルートがあるときのみ「▶ 音声案内を開始」。開始時はいつもの地図＋音声案内を表示。
4. 案内中に地図上部の **📡** を押すとレーダー画面へ。レーダーは現在の案内GPS監視を流用して目的地への直線距離を表示。GPS監視・記録を増やさない。
5. レーダー画面の **「🔈 音声案内へ戻る」** で通常地図＋音声案内へ復帰。レーダー表示中は既存仕様どおり右左折の音声を抑制。戻ると以後の案内音声が使える。切替時にルート再計算、案内のリセット、GPX記録の破棄は行わない。

## 変更点と非変更点

- 変更：`index.html` の走行メニュー、`ride-radar.js` の単独レーダー起動経路除去と案内専用レーダー、`mobile-ui.js` の走行後GPX欄表示、`style.css` のレーダー見出し、`sw.js` キャッシュ更新。
- 非変更：`app.js` のルート計算・GPS追従・自動リルート、`track-recorder.js` の実測点記録・GPX出力、車種別BRF、カスタマイズ幅、マイルート集、地点検索。
- GPX実測軌跡は従来どおりブラウザローカル保存。ユーザーが明示的に破棄するまで残る。バックグラウンド／画面消灯後の長時間記録は保証しない。
- 背景地図のオンライン制約は今回の変更では解消していない。
