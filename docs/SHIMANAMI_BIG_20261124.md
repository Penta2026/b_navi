# B_Navi 126cc以上・しまなみ島渡りモード（2026-11-24）

## 初回実装
- 126cc以上で、出発地・経由地・目的地を結ぶ中にしまなみ海道の島渡りが必要な場合だけ、確認ポップアップを表示する。通常探索と島渡りモードを選択可能。閉じたら検索を中止し、高速利用を黙って許可しない。
- 判定エリアは従来の「しまなみ7島＋尾道駅付近」。**全地点が範囲内**の場合に限る。広島市・福山市・松山市等の範囲外地点が入った長距離自動検出は今後の拡張課題。
- 連続する登録地点間で**島を渡る区間のみ**、126cc以上のバイク一般道BRFを基礎に高速・有料を一時許可。島内だけなら元の基本モード・好みのオプションを使用。元の車種と保存済みルート設定を変更しない。
- ファストトラベル用の自動車向けKinematicModelは島渡り中には使わず、二輪車の motorcycle=no、vehicle=no、access=no、一方通行、路面等の制約を保持したBRFを使用。
- 島を渡る場合は実際のBRouter応答から得た道路形状だけを利用する。6橋の原付・自転車向け参考線は附近を通ったかの**検証専用**で、走行GPXやナビ線には挿入しない。道路線が橋から著しく離れているときや経由地点で接続しないときは、案内可能な経路を偽造せず失敗とする。
- 区間別エラー表示、GPXの結合、右左折ヒントのoffset再設定、リルートと端末保存のモード記録を組み込む。

## 注意点
- しまなみICにはハーフインターがあり、出入口方向が限定。現行の道路判定はBRouterのOSM道路網と一方通行タグに依存し、**各ICを独立に現地法規検証できたわけではない**。
- 公開BRouterで指定地点を実計算した成功、走行中のGPS案内、安全なIC出入り、料金見積もり、リアルタイム通行止めは未確認。ネットワークや道路データが不十分な場合は経路計算を失敗とする。
- 出発地が範囲外になるケース、IC指定アンカー強制、分割境界の高さが異なる並走道路接続は今後の検証が必要。
- 道路規制の公式参考 https://www.jb-honshi.co.jp/customer_index/guide/jct-ic/jct_ic_e.html
