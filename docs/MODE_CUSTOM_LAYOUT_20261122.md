# B_Navi PWA — 2026-11-22: 走り方セレクターとカスタマイズ分離

## 要件
排気量の横に、従来の「ビギナー／一般／探索」を残す。126cc以上では既存のファストトラベルも残す。下段に3軸パラメータのカスタマイズを表示する。

## 動作
- 通常モードは排気量と走り方の組み合わせで、対応する既存BRFをそのまま使う。以前は公開BRouter問い合わせが強制的に `mode=1` だったのを修正。
- カスタマイズは下段の開閉パネルから「カスタマイズで計算する」をONにしたときのみ有効。基準はその排気量の「一般」BRF。変更していない状態（0/0/0、許可オプションOFF）は元の一般BRFと同一。
- スライダー操作／高速有料チェック／プリセット呼び出しはカスタマイズONに切り替える。通常の走り方を選択するとカスタマイズをOFFにするが調整値は消さない。
- 旧版で保存済みの非ゼロ調整値は、初回の設定移行でONとして扱う。
- 経路計算時の車種・モード・カスタマイズをスナップショットし、GPSリルート時に再使用する。しまなみ島内のBRouter分割計算にも選択モードを渡す。
- マイルート／オフライン経路の保存データは計算モードとカスタムON情報を保持。旧保存データは一般モードとして復元し、非ゼロカスタムのみ推定する。
