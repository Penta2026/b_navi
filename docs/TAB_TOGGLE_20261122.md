# B_Navi モバイル下部タブの再タップで最小化（2026-11-22）

## 要件と動作
- 「ルート」タブ：ルートパネルが開いている状態で再タップすると最小化。再タップすると元のパネルを表示。地図は広く見える。
- 「検索」タブ：検索を開いた状態で同じタブを再タップすると閉じ、もう一度押すと再表示。検索語・検索結果のDOMは保持する。
- 「お気に入り」も同様にトグル。「地図」でルートも検索も閉じる。他のタブへ移動したら前のパネルを閉じる。
- ルート下部の「━ ルート」ハンドルは従来どおり使える。

## 技術上の要点
- 既存の場所検索はモーダル `showModal()` だったため、開くと下部タブが押せなかった。
- モバイルのみ `place-dialog.show()`（非モーダル）＋下部ツールバーの上に固定するCSSに変更。PCの検索は `showModal()` のまま。
- `syncToolbar()` で表示パネルに応じてアクティブ表示と `aria-expanded` を同期。
- 検索ダイアログはクローズ時に要素を破棄しないので、入力値と結果は維持。`close` イベントで手動閉鎖・キーボード閉鎖も同期。
- ルート計算、BRF、GPS、ルート状態、GPX保存および保存領域の処理は変更なし。
