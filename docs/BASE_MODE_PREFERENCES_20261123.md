# B_Navi基本3モード＋追加オプション 試験仕様（2026-11-23）

## ユーザーが決めた設計
基本モード（ビギナー／一般／探索）を維持し、景色と距離（そのまま／景観優先／距離優先）、走り心地（そのまま／快走優先／効率優先）、裏道優先（ON/OFF）を組み合わせる。3×3×2=18通り、基本3モードで54通り。50cc/125cc/126cc以上を対象。126cc以上のファストトラベルは独立のまま。
信号回避は基本3モードで共通強化（初期試験値: OSM `traffic_signals` ノードコスト850）。最優先なのは交通ルール・進入禁止などの安全/法令の通行制約。

## ベンチマークの走り方
ユーザー提供の冨田さん型ルートを検証の参考にする。

- 福山から国道486号を通り、福富ダム、志和を経由して白木方面に抜ける
- そこそこ道幅がある、停止が少なく流れが良いという利用者の走行経験
- 最短より走りやすい道なら、**距離＋約20％でもよい**という方向性

具体的な発着点と真の最短距離、交通量、信号数、走行時間を測定したわけではない。地理的経路の完全一致はまだ検証していない。「約20％」は調整の目標であり、計算機によるハードな上限ではない。BRouterの単一BRFは「最短と比較して20％以内」を単独で保証しない。

## 現行初期試験係数の意味
- 信号: 850（すべての基本3モード）。BRouterに登録された信号ノードのみ。無登録信号やリアルタイムの渋滞は評価対象外
- 景観優先: RD5に森林/水辺の推定タグがある場合だけ自然景観を加点。実際の眺望の保証はない
- 距離優先: 通行許可済み道路のソフトコスト差を0.65倍に近づけ、距離の相対重要性を高める
- 快走優先: 1車線/1.5車線など狭路推定と右左折を抑える
- 効率優先: 右左折・狭路・生活道路を抑制し、停止の少なさと道路連続性を優先する。ただし交通流・到着時間の実測値は持たない
- 裏道優先: **基本モード別**に係数を調整。ビギナーは狭い道と右左折の増加を抑制、一般は快適な地域道重視、探索は細道と右左折を比較的許容。通行禁止道路や車庫/私道は推奨しない

## 限界・次の検証
1. 同じ出発/目的地点で、基本3モード×18通りを比較。比較対象に最短ルートと冨田さん型経由ルートを用意
2. 信号数・右左折回数・距離倍率・地域道比率・狭路比率を集計。数字は実路線から取得できる場合だけ表示
3. 距離倍率が約1.2になるケースで走行性を評価し、必要なら850・道幅係数・道路種別を調整
4. コードのユニットテスト＝ブラウザ実機/公開BRouterでの実計算成功、ではない
5. 公開BRouterのカスタムプロファイル利用時のみオプションと共通信号強化が反映。専用Java APIではオプションは拒否し、オプションなしの従来ルートは維持。ファストトラベルも現行を維持
6. 保存済みの旧4スタイルは新オプションへ移行。旧BRFで作成した保存済みルートの表示と法的ゲートは改ざんしない

※実時間速度データなしで「この道が必ず速い」「渋滞を避けた」とは宣言しない。
